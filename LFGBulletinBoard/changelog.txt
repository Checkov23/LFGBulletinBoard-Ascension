Group Bulletin Board 	

1.04
- Mythic+ recognition widened. A keystone link still wins outright; on top of
  that "mythic", "+11", "M+" and "11 key" are now matched by pattern, because
  the tokeniser destroys punctuation and those can never match as plain words.
  Only a keystone link removes the Trade category, the looser patterns just add
  Mythic+, so "WTS +15" stays a sale.
- CoA category level ranges widened to 1-60. A narrow range only gave the level
  filter a way to hide these categories from the people who want them.
- New /gbbraw command. It prints the next channel lines exactly as the addon
  receives them, pipes doubled so hyperlinks stay readable, together with the
  categories each line matched. For working out why a specific line is not
  picked up instead of guessing.

1.03
- Fixed the options panel crash introduced with the CoA categories. The
  localisation panel reads the English fallback name table behind
  GBB.dungeonNames and concatenates the value with no nil check; the CoA names
  had only been written to the front table. They now go into both.
  That single crash was behind all three reported symptoms: empty window,
  missing minimap button, and only the WotLK instances in the settings, because
  it aborted Init before any of that was built.
- Keystones are posted as an item link. The tokeniser turns the link prefix into
  the word "hitem", which upstream files under Trade, so every keystone request
  was landing there. Keystone lines now drop Trade, pin to Mythic+, and count as
  a request even when the poster writes no role word.
- AscensionContent.lua moved after RequestList.lua in the TOC, since it now
  wraps GBB.GetDungeons.
- New tools/loadtest.mjs: runs the addon in a Lua VM against a stubbed 3.3.5a
  API and asserts that Init completes, the minimap button exists, the Classic
  filter panel is built, and a real keystone line lands in Mythic+.

1.02
- FontString:SetMaxLines removed. Like SetScale before it, that method does
  not exist on a 3.3.5a FontString. It aborted OptionsInit at the channel
  checkboxes, so the TBC and Classic filter panels were never built, and it
  aborted UpdateList, so the window stayed empty. The minimap button was
  missing for the same reason: Init never got that far.
- New GBB.Compat.TryCall for methods that may be absent
- check335.mjs now rejects ANY method sent to a FontString that is not in
  the 3.3.5a FontString API, which is the class of bug behind both crashes
- CoA categories moved from the WotLK block to the Classic block, because
  CoA runs vanilla content
- Classic dungeon filters now default to on. Upstream ships them off, which
  left the board empty on a vanilla-content server
- Version scheme switched to a simple running number

1.01 (published as 2.64-ascension2, renumbered)
- FontString:SetScale removed. SetScale is a Frame method on 3.3.5a, so scaling
  a FontString threw and aborted Init before the minimap button was created.
  All scaling now goes through GBB.Compat.ScaleRegion, which scales frames
  normally and FontStrings through their font height.
  Reported in game on Rexxar (Conquest of Azeroth).
- All comments and messages translated to English
